# Bundled fonts

The website bundles unmodified webfont files for offline use, including Latin and Vietnamese glyph subsets. Each family uses the SIL Open Font License 1.1. Full licenses are provided beside the font assets.

- [DM Sans](https://github.com/google/fonts/tree/main/ofl/dmsans) — assets/fonts/dmsans-OFL.txt
- [Manrope](https://github.com/google/fonts/tree/main/ofl/manrope) — assets/fonts/manrope-OFL.txt
- [Playfair Display](https://github.com/google/fonts/tree/main/ofl/playfairdisplay) — assets/fonts/playfairdisplay-OFL.txt

Webfonts obtained from Google Fonts on 7 October 2026. See server/fonts.css for font-face declarations and language subsets.
